## 通用约定

### HTTP 状态码约定

所有客户端接口**始终返回 HTTP 200**。客户端通过 JSON body 中的 `code` 字段区分业务结果，无需关注 HTTP 状态码。

### 请求头

| Header         | 必填 | 说明                                                                                    |
|----------------|------|-----------------------------------------------------------------------------------------|
| `Content-Type` | 否   | GET 请求无请求体，可省略；若需 protobuf 响应，填 `application/x-protobuf`              |

此接口**无需**携带 `Authorization` Header。

> 响应格式与请求 `Content-Type` 保持一致：不填或填 JSON 则响应 JSON，填 protobuf 则响应 protobuf 二进制。

每个响应均携带以下 Header：

| Header          | 说明                                                |
|-----------------|-----------------------------------------------------|
| `X-Server-Time` | 服务器当前时间戳（Unix 毫秒），可用于客户端时间校准 |

### 序列化格式

**响应体（下行）**：由请求 `Content-Type` 决定

| Content-Type                                             | 响应序列化方式  |
|----------------------------------------------------------|-----------------|
| 不填 / `application/json`                               | JSON            |
| `application/x-protobuf` / `application/protobuf`       | Protobuf 二进制 |

Proto 定义文件见 `pb/cs.proto`，C# 命名空间为 `Cspb`，相关消息：`ServerTimeReq`、`ServerTimeResp`、`ServerTimeData`、`ErrorResp`。

> **错误响应的 protobuf 兼容性**：所有 `*Resp` 消息的前两个字段（tag 1 = `code`，tag 2 = `message`）与 `ErrorResp` 保持一致，客户端可直接用具体 `*Resp` 类型解析错误响应，无需额外分支。

### 统一响应结构（JSON 模式）

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| 字段      | 类型   | 说明                                     |
|-----------|--------|------------------------------------------|
| `code`    | int    | `0` 表示成功，非 `0` 为业务错误码       |
| `message` | string | 结果描述，成功时为 `"ok"`                |
| `data`    | object | 成功时的业务数据，失败时为 `null` 或省略 |

## 获取服务器时间

### `GET /api/serverTime`

获取服务器当前时间戳（Unix 毫秒）。无需认证，客户端可在任意阶段调用，常用于时间校准和倒计时同步。

#### 请求参数

无请求体，无 Query 参数。

#### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "serverTime": 1752393600000
  }
}
```

| 字段         | 类型  | 说明                                |
|--------------|-------|-------------------------------------|
| `serverTime` | int64 | 服务器当前时间戳（Unix 毫秒）       |

#### 错误响应

此接口无业务参数校验，正常情况不返回业务错误。

| 业务错误码 | message                 | 说明               |
|------------|-------------------------|--------------------|
| `2500`     | `internal server error` | 服务端内部错误     |

## 错误处理

### 客户端建议处理策略

| 错误码            | 处理方式                                                       |
|-------------------|----------------------------------------------------------------|
| `2500`            | 时间校准失败，降级使用本地时间；可上报日志，游戏流程正常继续  |
| 网络错误（超时 / 无响应） | 使用本地时间兜底，不阻塞游戏启动流程                  |
